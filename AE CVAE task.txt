研究目標如下：

我想比較兩種 representation：

==================================================
四、模型需求
==================================================

請使用 PyTorch 實作。

--------------------------------------------------
1. AutoEncoder
--------------------------------------------------

Input:
  x: [batch_size, input_dim]

Encoder:
  x -> H_AE

Decoder:
  H_AE -> x_recon

Loss:
  reconstruction_loss = MSE(x_recon, x)

請允許 config 控制：
- input_dim
- latent_dim
- hidden_dims
- dropout
- activation
- batch_norm 是否使用
- reconstruction loss 類型，目前至少支援 mse，可預留 cosine / l1

--------------------------------------------------
2. Conditional Variational AutoEncoder, CVAE
--------------------------------------------------

Input:
  x: [batch_size, input_dim]
  c: [batch_size, condition_dim]

Encoder:
  concat(x, c) -> hidden -> mu, logvar

Reparameterization:
  z = mu + eps * std

Decoder:
  concat(z, c) -> x_recon

Loss:
  recon_loss = MSE(x_recon, x)
  kl_loss = KL(q(z|x,c) || N(0,I))
  total_loss = recon_loss + beta * kl_loss

請支援 beta-VAE 形式：
  total_loss = recon_loss + beta * kl_loss

beta 可由 config 控制。

請輸出：
- z
- mu
- logvar
- x_recon

CVAE 的 latent vector H_CVAE 建議預設使用 mu，因為 inference / evaluation 較穩定。
請在程式中允許設定 latent_representation = "mu" 或 "z"。

--------------------------------------------------
3. Latent classifier
--------------------------------------------------

請實作一個簡單分類器，用於比較 H 的分類能力。

至少支援：

- Random Forest
- MLP classifier

如果 tactic_label 是多類別分類，請輸出：

- confusion matrix

注意：

不要在 AE / CVAE 訓練過程中直接把分類 loss 混進去，除非另外開 config 選項。
第一版請先以 representation evaluation 為主。

==================================================

請實作以下實驗流程。

--------------------------------------------------
Experiment A：AE baseline
--------------------------------------------------

流程：

1. load payload embeddings x and labels y
2. split train / val / test
3. train AE on train x
4. extract H_AE for train / val / test
5. train classifier on H_AE_train, y_train

輸出：

- latent embeddings 檔案
- visualization plots
- report

--------------------------------------------------
Experiment B：CVAE oracle-condition representation test
--------------------------------------------------

流程：

1. load payload embeddings x and labels y
2. load tactic condition embeddings C
3. 對每筆資料，用其正確 tactic label 對應到 C
4. train CVAE on (x, C)
5. extract H_CVAE = mu or z
6. train classifier on H_CVAE_train, y_train
7. evaluate on H_CVAE_test
8. run clustering / visualization on H_CVAE

重要警告：
這個實驗使用正確 C，因此可能有 label leakage。
所以請在報告中清楚標註：
"CVAE oracle-condition classification is not a pure payload-only tactic prediction test. It evaluates whether latent representation becomes more tactic-aligned when conditioned on known tactic descriptions."

輸出：
- CVAE reconstruction loss
- KL loss
- total loss
- tactic classification metrics
- latent embeddings
- visualization plots
- report

--------------------------------------------------
Experiment C：CVAE compatibility test
--------------------------------------------------

這個實驗非常重要，目的是避免單純把正確 C 當答案餵給模型。

測試方式：

對每一個 test sample x_i：
  將它分別搭配所有 candidate tactic conditions C_k。
  對每一組 (x_i, C_k) 計算：
    - reconstruction error
    - optionally negative ELBO
  選擇 reconstruction error 最低或 score 最佳的 tactic 作為 predicted tactic。

也就是：

score(x_i, C_k) = recon_loss 或 recon_loss + beta * KL

predicted_tactic = argmin_k score(x_i, C_k)

請實作：

compatibility_test.py

輸出：
- score matrix: [num_samples, num_tactics]
- predicted tactic
- accuracy
- macro F1
- confusion matrix
- 每個 tactic 的平均 compatibility score
- CSV / JSON 結果檔

這個實驗的意義：
檢查 payload x 和哪一個 tactic description C 最相容，而不是直接把正確 label 塞進模型。

十三、重要研究解讀與 warning
==================================================

請在 report.md 與 README.md 中明確寫出以下觀念：

1. AE H 分類：
   - 用來測試 payload embedding 本身是否已經具有 tactic-level 可分性。
   - 這是 baseline。

2. CVAE oracle-condition H 分類：
   - 使用正確 tactic description 作為 condition C。
   - 因此不能直接視為純 payload-only classification。
   - 它比較像是在測：當 tactic knowledge 已知時，latent space 是否更能對齊 tactic 語意。

3. CVAE compatibility test：
   - 對同一個 payload 搭配所有 candidate tactic descriptions。
   - 用 reconstruction error 或 negative ELBO 判斷 payload 與 tactic condition 的相容性。
   - 這比較接近實際 tactic 推論。

4. condition ablation：
   - 用來檢查 C 是否真的有作用。
   - 如果 full / short / keywords / random / wrong condition 結果差不多，代表 CVAE 可能沒有真正使用 tactic semantics。
   - 如果換錯 C 後 reconstruction 或 compatibility 明顯變差，代表 condition C 可能有提供有效語意約束。

5. payload embedding input 的限制：
   - 模型學到的是 embedding model 已經轉換過的 payload 語意，而不是 raw packet 本身。
   - 如果 embedding model 不懂資安語意，H 可能只反映一般文字相似性。
   - 因此後續可以比較不同 payload embedding 方法。
